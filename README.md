
# StoreDesk

StoreDesk is a Python-based application project.

## Tech Stack

- Python 3.11
- Boto3 (AWS SDK for Python)

## Project Structure

```text
storedesk/
├── app/
├── data/
├── docs/
├── tests/
├── requirements.txt
├── README.md
└── .gitignore
```

## Setup Instructions

### 1. Clone the repository

```bash
git clone <repository-url>
cd storedesk
```

### 2. Create virtual environment

```bash
py -3.11 -m venv venv
```

### 3. Activate environment

Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```
